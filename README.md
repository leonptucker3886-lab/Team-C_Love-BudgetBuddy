# Team C_Love-BudgetBuddy

A monthly budget planner that runs in any browser. $4.99 one-time, no subscription.

## Features
- Categories with a monthly budget, progress bars and red over-budget warnings
- One-click starter categories for new users
- Log spending (date, category, note); spent and left per category
- Bar chart of budget vs spent per category
- Income and monthly totals (budgeted, spent, left)
- Unbudgeted income ("give every dollar a job"); turns red if you budget more than you earn
- Switch months and copy last month's budget forward
- Export the month's spending to CSV
- Currency picker and dark mode
- Dated backup export; import validates the file and confirms before replacing data
- Data stays in your browser: no account, no bank login, no ads

## Run
Open `index.html` in any modern browser. No build step, no server.
